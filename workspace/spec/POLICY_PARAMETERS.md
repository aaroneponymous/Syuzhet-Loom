# Policy parameters: meeting-room booking (example)

Numbers the decisions refer to. A parameter can change without changing the decision that uses it.

| Id | Parameter | Value | Used by |
|---|---|---|---|
| PN-01 | Hold period: how long a hold lasts without being confirmed. | 5 minutes | D-08 |
| PN-02 | Check-in window: how long before the start check-in opens. | 10 minutes | D-15 |
| PN-03 | Grace period: how long after the start a booking waits for check-in before it is released. | No value yet (Q-03) | D-16 |
