# Brand

| File | Use |
|---|---|
| `syuzhet-loom-logo-light.svg` | The Syuzhet Loom logo for light backgrounds |
| `syuzhet-loom-logo-dark.svg` | The same logo for dark backgrounds |

The two files differ only in colour. The text is live SVG text (Georgia for the name, the system sans-serif for the tagline), so it is drawn with the reader's fonts.

The small mark used in the viewer header and as its favicon is a separate, simplified drawing: `src/viewer/assets/brand/`.
